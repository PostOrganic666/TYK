# Тык

«Тык» — полноэкранная офлайн-песочница для маленьких детей на macOS. Она
перехватывает клавиатуру, мышь и системные сочетания, а вместо рабочего стола
показывает одну спокойную игровую сцену.

Проект основан на механике блокировки из
[Toddler Mode for Mac](https://github.com/js1664/Toddler-Mode-for-Mac) и
распространяется по лицензии MIT. Игровое содержимое форка создано заново.

## Режимы

- **Буквы** — все 33 русские буквы с офлайн-озвучкой; цвет, размер и положение
  меняются при каждом нажатии.
- **Животные** — 30 оригинальных книжных иллюстраций с названиями.
- **Транспорт** — 30 видов техники и транспорта в том же стиле.
- **Музыка** — десять согласованных нот на семплированной челесте из
  системного General MIDI soundbank macOS.

В режимах нет рекламы, аккаунтов, сети, очков, побед, конфетти и бесконечных
случайных объектов. На экране всегда находится один главный предмет.

## Безопасный выход

По умолчанию детский режим завершается сочетанием `⌘⇧Esc`. Дополнительно можно
включить простой пример или пароль. Аварийный выход из базовой механики форка
сохранён.

## Сборка

Локальная сборка требует Xcode:

```sh
./ToddlerLock/build-local.sh
```

Если Xcode на компьютере нет, workflow **Build Tyk** собирает ad-hoc подписанный
архив `Tyk-macOS.zip` на GitHub Actions. Такая сборка предназначена для личной
установки; публичному релизу понадобится собственная Developer ID подпись и
нотарификация Apple.

## Конфиденциальность

Приложение работает офлайн и не запрашивает доступ к фото или камере. Для
системной блокировки требуется только разрешение
**Конфиденциальность и безопасность → Универсальный доступ**.
