# Тык

«Тык» — полноэкранная офлайн-песочница для маленьких детей на macOS. Она
перехватывает клавиатуру, мышь и системные сочетания, а вместо рабочего стола
показывает одну спокойную игровую сцену.

Проект основан на механике блокировки из
[Toddler Mode for Mac](https://github.com/js1664/Toddler-Mode-for-Mac) и
распространяется по лицензии MIT. Игровое содержимое форка создано заново.

## Режимы

- **Буквы** — все 33 русские буквы с офлайн-озвучкой; цвет, размер и положение
  меняются при каждом нажатии.
- **Алфавит** — 33 буквы по порядку, к каждой по одному тыку добавляются три
  знакомые картинки с озвучкой Kore.
- **Животные** — 90 книжных иллюстраций зверей, птиц, насекомых и морских обитателей.
- **Транспорт** — 50 видов техники и транспорта в том же стиле.
- **Дома** — 50 знакомых предметов кухни, ванной, прихожей и комнаты.
- **Музыка** — десять согласованных нот на семплированной челесте из
  системного General MIDI soundbank macOS.

Буквы и картинки озвучены женским голосом Kore из Gemini TTS. Все 224 записи
(190 картинок, 33 буквы и приветствие) входят в приложение и проигрываются
офлайн. Новый элемент без записи временно использует системный русский голос.

Общая настройка **Пауза** задаёт интервал между тыками (0–10 секунд, по
умолчанию 2). Озвучка всегда заканчивается до следующей карточки; быстрые
нажатия игнорируются. Музыка реагирует сразу.

В режимах нет рекламы, аккаунтов, сети, очков, побед, конфетти и бесконечных
случайных объектов. В карточках показывается один главный предмет; в алфавите — буква и до трёх примеров.

## Безопасный выход

По умолчанию детский режим завершается сочетанием `⌘⇧Esc`. Дополнительно можно
включить простой пример или пароль. Аварийный выход из базовой механики форка
сохранён.

## Сборка и установка

Локальная сборка требует Xcode:

```sh
./ToddlerLock/build-local.sh
```

Если Xcode на компьютере нет, workflow **Build Tyk** запускается после push в
`main` или `codex/**` и вручную через Actions. Он проверяет покрытие озвучки,
собирает universal-приложение для Apple Silicon и Intel, подписывает ad-hoc
и сохраняет архив `Tyk-macOS.zip`. Для ветки `codex/toddler-fork` также создаётся
prerelease [v0.5.0](https://github.com/PostOrganic666/TYK/releases/tag/v0.5.0).
Для установки завершить старое приложение, распаковать архив и заменить
`/Applications/Тык.app`. Настройки сохраняются под тем же bundle ID `local.tyk.app`. Такая сборка предназначена для личной
установки; публичному релизу понадобится собственная Developer ID подпись и
нотарификация Apple.

## Конфиденциальность

Приложение работает офлайн и не запрашивает доступ к фото или камере. Для
системной блокировки требуется только разрешение
**Конфиденциальность и безопасность → Универсальный доступ**.

## Каталог картинок

[Алфавит: 33 буквы и 99 примеров](ToddlerLock/catalog/ALPHABET.md).

[Полный каталог](ToddlerLock/catalog/README.md) отмечает сохранённые и новые картинки.
Машиночитаемый список: `ToddlerLock/catalog/pictures.json`; промпты новых листов:
`ToddlerLock/catalog/generation.json`. Покрытие озвучки и файлы отмечены в каталоге
и `ToddlerLock/catalog/speech.json`. Проверка недостающих записей:
`python3 ToddlerLock/tools/generate_speech.py --check`. Все ресурсы доступны офлайн.

## Генерация озвучки

[Пайплайн озвучки](ToddlerLock/catalog/SPEECH_PIPELINE.md) описывает источники
названий, генерацию через OpenRouter, нарезку тишины, продолжение после сбоя,
проверку покрытия и добавление записей в Xcode. Для подготовки нужен Python 3
и локальный API-ключ; для игры и GitHub-сборки ключ и сеть не нужны.
