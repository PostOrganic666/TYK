# Подготовка офлайн-озвучки «Тык»

Тип: `RUNBOOK`.
Назначение: воспроизводимо добавлять записи для букв и картинок и проверять покрытие.
Когда читать: при добавлении элемента, изменении произносимого названия или замене голоса.
Не содержит: API-ключи, журналы запросов и инструкции по публичной публикации.
Правило обновления: менять при изменении формата каталога, генератора или загрузки ресурсов.

## Источники и результат

- Названия картинок: `ToddlerLock/Modes/PictureMode.swift`; каталог с теми же
  ID и названиями: `catalog/pictures.json`. Генератор требует их совпадения.
- Примеры алфавита: `catalog/alphabet.json` и `Modes/AlphabetCards.swift`.
  Слова с одинаковым названием используют одну запись; новые слова получают
  стабильный ID `alphabet-word-<hash>`. Проверка сверяет 33 буквы, порядок
  примеров, по три слова и наличие целевой буквы в каждом слове.
- Буквы и произношение: `ToddlerLock/Modes/RussianAlphabet.swift`.
  Режим «Буквы» использует короткое `spokenName` и файлы `letter-<код>`.
  Режим «Алфавит» использует `alphabetSpokenName`: «Тэ. Буква тэ.»
  и отдельные файлы `alphabet-letter-<код>`. Карточки используют прежние записи.
- Приветствие для проверки голоса: «Привет! Давай играть!».
- Голос: Kore, женский; модель `google/gemini-3.8-flash-tts` через OpenRouter.
  Манера речи не задаётся отдельным промптом; русские слова передаются как текст.
- Готовые файлы: `ToddlerLock/Resources/Speech/<ID>.wav`, PCM 24 кГц, 16 бит, моно.
- `catalog/speech.json` содержит точный текст, модель, голос, путь, длительность,
  SHA-256, сведения о нарезке и ID генерации, если API его вернул.
- `catalog/pictures.json` содержит отметку `speech` у каждой готовой картинки.
- `ToddlerLock/Resources/Speech/speech-index.json` связывает произносимый текст
  с basename записи для приложения. Xcode копирует эти файлы в ресурсы bundle.

Команды ниже запускаются из корня репозитория. Нужен Python 3;
дополнительные библиотеки, ffmpeg и локальный Xcode для генерации не нужны.

## Добавить элемент или изменить название

1. Обновить runtime-список и соответствующую запись `pictures.json`. Для буквы
   обновить `RussianAlphabet.swift`. ID картинки остаётся стабильным.
2. Проверить, что именно нужно озвучить:

   ```sh
   python3 ToddlerLock/tools/generate_speech.py --check
   ```

   Строка `MISSING: ID — текст` и ненулевой exit code означают отсутствие
   актуальной записи. Старый файл с другим текстом или повреждённым hash не
   считается покрытием. Проверка не использует ключ и сеть.

3. Положить локальный OpenRouter API-ключ в `Key.txt` (он исключён из Git) или
   указать другой закрытый файл. Не добавлять ключ в код, workflow или ресурсы.

   ```sh
   python3 ToddlerLock/tools/generate_speech.py --key-file Key.txt
   ```

   Генератор обращается к `POST https://openrouter.ai/api/v1/audio/speech`.
   Один запрос — один элемент. Записи формируются сразу отдельно: внутри длинной
   общей фразы не приходится угадывать границы слов. На концах удаляется тишина,
   сохраняются короткие поля перед и после речи. Только для `alphabet-letter`
   внутренние участки тишины дольше 450 мс сокращаются до 300 мс;
   сохраняются края паузы, чтобы не обрезать тихие согласные. Стандартно выполняются четыре
   запроса одновременно; можно задать `--workers 1` для последовательного режима.

   Уже готовые записи с совпадающими текстом, моделью, голосом и hash пропускаются.
   Результат каждого успешного запроса сразу сохраняется. После сбоя повторить
   команду: она продолжит с недостающих записей. После полного успеха обновляются
   runtime index, поля `speech` и ссылки в читаемом каталоге.

4. Зарегистрировать ресурсы и повторить проверку:

   ```sh
   python3 ToddlerLock/generate_project.py
   python3 ToddlerLock/tools/generate_speech.py --check
   ```

5. Прослушать новые и изменённые записи по ссылкам в `catalog/README.md`.
   Проверка файлов и hash подтверждает покрытие, но не заменяет оценку
   произношения. Для коротких названий и букв распознавание может ошибаться.
6. Коммитить аудио, оба каталога, runtime index, источники и обновлённый Xcode
   project вместе. API-ключ не коммитить. Сборка GitHub не генерирует голос и не
   требует секрета OpenRouter: она использует готовые записи из репозитория.

## Работа в игре и сборка

`RussianSpeech` проигрывает bundle-записи через `AVAudioPlayer` с пользовательской
громкостью. Сохраняет задержку старта 0,18 с и прекращает речь при выходе
из режима. `isBusy` учитывает ожидающий старт, играющий WAV и системную речь.
`PacedPlayMode` применяет общий интервал между принятыми тыками и не пропускает
новое нажатие до конца речи. По умолчанию интервал 2 с, настройки позволяют
0–10 с; музыка запускается без этого фильтра. Нажатия отбрасываются, не копятся. Для неизвестного названия или
недоступного файла использует русский системный офлайн-голос.

По умолчанию сборку выполняем в GitHub Actions, workflow **Build Tyk**.
Локальная сборка — дополнительный вариант при наличии Xcode.
Оба варианта выполняют `--check` перед компиляцией.
Недостающая запись или несовпадение каталога/index/resources блокируют сборку.
При замене модели/голоса сначала подготовить и прослушать короткую пробу; затем
изменить `MODEL`/`VOICE` в генераторе. Такая смена делает прежние записи
неактуальными и приводит к их повторной генерации.
