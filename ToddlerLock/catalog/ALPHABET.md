# Алфавит с картинками

Режим содержит все 33 русские буквы и 198 примеров — по шесть на букву.

При входе показывается и произносится случайная буква. Три следующих принятых нажатия по одному добавляют картинки с названиями; открытые картинки остаются на экране. После третьей следующий тык убирает картинки и показывает другую букву с её озвучкой. Каждая буква даёт четыре озвучки: фразу «Тэ. Буква тэ.» и три слова.

Буквы проходят перемешанными кругами: каждая появляется ровно один раз за 33 показа. На стыке кругов между одинаковыми буквами остаётся не менее восьми других букв. При новом входе в режим начинается новый случайный круг.

У каждой буквы своя очередь из шести перемешанных картинок. За один показ открываются три разных примера, при следующем появлении этой буквы — остальные три. После всех шести очередь перемешивается снова; между повторами одного примера остаются не менее трёх других примеров этой буквы. Выбранные картинки и их порядок сохраняются до окончания текущего показа.

Клавиши и мышь работают одинаково. Нажатия во время речи или паузы игнорируются, очередь не создаётся. Настройка «Пауза» общая для всех игровых режимов, кроме музыки: 0–10 секунд с шагом 0,5, по умолчанию 2 секунды. Время считается от последнего принятого нажатия. Даже при 0 секундах речь всегда дослушивается до конца. Без звука действует только выбранный интервал. Комбинация выхода не проходит через этот фильтр.

Буква выделяется цветом внутри подписей. Для Ы, Ь и Ъ выбраны слова, содержащие букву; на этих экранах есть пояснение. Если у других букв показаны примеры с буквой внутри слова (например, «мёд» для Ё), появляется подсказка «В начале и внутри слова».

Все картинки и озвучка Kore входят в приложение и работают офлайн. Добавлены 99 примеров: 78 используют готовые иллюстрации, 21 — новые. Для новых названий записаны 24 дополнительных слова; остальные используют существующую озвучку. У слова «и́рис» явно задано ударение для названия цветка.

Обзор всех шести примеров: [А–Й](alphabet-expansion-2026-11/preview-1.jpg), [К–Ф](alphabet-expansion-2026-11/preview-2.jpg), [Х–Я](alphabet-expansion-2026-11/preview-3.jpg). Новые иллюстрации созданы встроенным image_gen; [точные промпты, исходники и контрольные суммы](alphabet-expansion-2026-11/generation.json). Игровые PNG находятся в `ToddlerLock/Resources/Alphabet/`; подготовка и обзор — `tools/import_alphabet_expansion.py`.
