# Карточки «Еда»

50 отдельных иллюстраций знакомых продуктов и домашних блюд для раздела «Еда».
Названия короткие и совпадают с текстом озвучки. Это словарь для игры, а не меню.

- [Список и точные промпты](items.json): тема каждого изображения и полный промпт.
- Генерация: встроенный инструмент imagegen, по одному прозрачному изображению на карточку.
- Стиль: акварель и цветной карандаш, естественные цвета еды, простые узнаваемые силуэты без лиц, надписей и упаковочных брендов.
- Исходники: `originals/<asset>.png`.
- Ресурсы приложения: `../../ToddlerLock/Resources/Pictures/Food/<asset>.png`, RGBA 512 × 512.
- [Обзор всех 50 карточек](../food-added.jpg).
- Озвучка: Kore, тот же генератор и формат WAV, что у остальных разделов; ссылки находятся в [общем каталоге](../README.md).

Нормализация размера и создание обзорного листа:

```sh
python3 ToddlerLock/tools/import_food.py
python3 ToddlerLock/generate_project.py
python3 ToddlerLock/tools/audit_picture_catalog.py
python3 ToddlerLock/tools/generate_speech.py --check
```

Для нормализации и визуального аудита нужен Pillow. Генератор озвучки работает без дополнительных Python-библиотек.
