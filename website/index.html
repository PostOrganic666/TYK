Frequently Asked Questions

How do I lock my MacBook keyboard for my toddler?

Download Toddler Mode for Mac, grant Accessibility permission, pick a play mode, and click Lock Now. Your toddler sees colorful animations while all keyboard shortcuts and system controls are blocked.

Can my toddler accidentally close or exit the app?

No. Toddler Mode blocks all keyboard shortcuts including Cmd-Tab, Cmd-Q, Mission Control, and trackpad gestures. The only way to exit is a special shortcut that requires pressing 2 or more modifier keys simultaneously, which toddlers cannot do. You can also add a password for extra safety.

Does it work on MacBook Air, MacBook Pro, and iMac?

Yes. Toddler Mode works on any Mac running macOS 13 (Ventura) or later, including MacBook Air, MacBook Pro, iMac, Mac Mini, and Mac Studio, with both Apple Silicon and Intel processors.

How do I prevent my baby from pressing buttons on my Mac?

Install Toddler Mode for Mac. It takes over the full screen and blocks every keyboard shortcut, trackpad gesture, and system control. Your baby can mash keys freely and only see fun colorful letters and hear pleasant sounds. It's the easiest way to baby-proof your MacBook keyboard.

What is the default exit shortcut?

The default exit shortcut is Cmd+Shift+Esc (⇧⌘Esc). You can change it to any key combination in settings — it just needs to include 2 or more modifier keys so your toddler can't trigger it by accident.

Is there an iPhone version of Toddler Mode?

Yes! Toddler Mode for iPhone brings the same play modes to iOS, plus a kid-safe family photo viewer and a pretend phone. It pairs with iOS Guided Access to fully lock the phone to the app. It's coming to the App Store; there is no Windows or Chromebook version.

How does the iPhone version keep toddlers from leaving the app?

Two layers: the app softens accidental swipes and hides the system chrome, and iOS Guided Access (which the app walks you through, and verifies, in about a minute) locks the phone to the app completely — the Home swipe and even the lock button can be disabled.

Can my toddler delete or share photos in the photo viewer?

No. The photo modes are display-only by design: there is no share, edit, or delete function anywhere in the app. You choose exactly which photos or albums are shown — hand-picked photos, chosen albums, or everything except albums you exclude.

Is Toddler Mode safe? Will it damage my Mac?

Completely safe. The app only intercepts input events and draws animations on screen. It doesn't modify system files, install drivers, or run in the background when not locked.

Is there a keyboard lock app for Mac?

Yes — Toddler Mode is a free, open-source keyboard lock app for Mac. It blocks all keyboard input, trackpad gestures, and system shortcuts so kids can safely play without affecting your computer.
